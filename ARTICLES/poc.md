# POC (Proof of Concept) for GatsbyJS

In this section, we will discuss two POC plugins that can be used with GatsbyJS. These plugins serve different purposes, but they are both crucial for developers looking to enhance their development process and explore new features.

## Archify POC Plugin

The first plugin discussed is Archify, or a plugin with similar functionality. [[2026-08-18]] is useful for rendering HLD (High-Level Design) in your GatsbyJS project. It allows you to create and manage high-level architecture diagrams directly within your site.

## Skill-Up POC Plugin

The second plugin is Skill-Up, or a plugin with similar functionality. Skill-Up aims to improve user skills within the application, offering various features such as tutorials, skill tests, and more. This plugin is designed to help users enhance their abilities and provide a more engaging user experience.

Both of these POC plugins can be integrated into your GatsbyJS project to add extra functionality and improve development efficiency.
